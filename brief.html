The brief (verbatim, typos and all)

Creative project. The iconic west pier in Brighton has been damaged further by this week's storms. It's a local cliche for artists and photographers. Search the internet for art, remained each image as the latest damaged view of of the pier. Collate the images into an online gallery. Host via free service. Landing page of the site should record how many images were found, how long you spent doing it. It's a statement on human vs AI creativity. Create a sepearte bot to do this. Keep this message and a log of what you did as a seperate page on the site. Create a credits page for artists. now go wild, create and show us what you can do.

Kept exactly as received, double spaces and all. "Remained" was read as re-name.

Method in one paragraph

The machine searched Wikimedia Commons (the Brighton West Pier category tree plus keyword searches for paintings, prints, postcards and starlings) and the Openverse index of Flickr's Creative Commons photos. It read each candidate's licence from the source API, discarded no-derivatives licences, built contact sheets, chose images for range rather than volume, re-checked every Flickr licence on the live Flickr page, downloaded web-sized copies (not cropped or edited) and generated this static site with a 200-line Python script. It is hosted free on GitHub Pages. Comments and the forum run on GitHub Discussions through giscus, so visitors need a GitHub sign-in to post.
